# ЛР5 — JSON и конвертации

## Цель работы
Научиться читать и записывать JSON и CSV, преобразовывать данные между форматами JSON ↔ CSV и CSV → XLSX.

## Структура
- `src/lab05/json_csv.py` — функции `json_to_csv` и `csv_to_json`.
- `src/lab05/csv_xlsx.py` — функция `csv_to_xlsx`.
- `data/samples/` — входные примеры.
- `data/out/` — результаты конвертаций.
- `images/lab05/` — скриншоты проверки XLSX (добавляются после открытия файла в Excel/LibreOffice).

## Установка
Из корня проекта выполните:

```powershell
python -m pip install -r requirements.txt
```

## Запуск конвертаций
Из корня проекта выполните:

```powershell
python -m src.lab05.demo
```

Команда запускает все три сценария и сохраняет результаты в `data/out/`. Запускать её нужно из корня проекта.

## Принятые решения
- Кодировка всех текстовых файлов — UTF-8.
- Для JSON → CSV порядок столбцов определяется первым появлением ключа при обходе объектов.
- Если у объекта нет какого-либо поля, в CSV для него записывается пустая строка.
- При CSV → JSON все значения остаются строками, как требует задание.
- Разделитель CSV определяется автоматически среди запятой и точки с запятой; если определить его не удалось, используется стандартная запятая.
- Пути задаются относительно корня проекта. Выходные папки создаются автоматически.
- Для XLSX используется `openpyxl`; лист называется `Sheet1`, ширина колонок рассчитывается по самой длинной ячейке и составляет минимум 8 символов.
- Некорректный JSON, пустые файлы, неподдерживаемая структура и неверные расширения вызывают `ValueError`. Отсутствующий входной файл вызывает `FileNotFoundError`.

## Демонстрация и проверка
1. **JSON → CSV.** Запустите первую команду. В `data/out/people_from_json.csv` должны быть заголовок `name,age,city` и 3 строки данных.
2. **CSV → JSON.** Запустите вторую команду. В `data/out/people_from_csv.json` должен появиться список из 3 объектов с ключами `name`, `age`, `city`.
3. **CSV → XLSX.** Запустите третью команду и откройте `data/out/people.xlsx` в Excel или LibreOffice. Проверьте наличие листа `Sheet1`, заголовков и подходящей ширины колонок.

Для отчёта добавьте скриншот открытого `people.xlsx` в `images/lab05/` и вставьте его сюда:

```markdown
![Проверка people.xlsx](images/lab05/people_xlsx.png)
```

## Ограничения
JSON → CSV поддерживает только непустой список словарей. Вложенные структуры JSON не разворачиваются в отдельные столбцы. CSV → JSON не преобразует типы: числа и другие значения сохраняются строками.
